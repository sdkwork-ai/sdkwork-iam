# static

Platform static assets for the `sdkwork-iam-uniappx` root (launch mark, shared
image assets). Tab-bar icons, when a target renders a native tab bar, live here as
paired filled/outline glyphs per `sdkwork-specs/ICON_SPEC.md` §3.2.

No binary assets are committed in this change; the release pipeline materializes
store-catalog media from `assets/`.
