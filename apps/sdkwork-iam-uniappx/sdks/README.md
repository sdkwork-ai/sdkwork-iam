# sdks

Generated SDK workspaces for the `sdkwork-iam-uniappx` root live in the
repository-level `sdks/` workspace (`@sdkwork/iam-app-sdk`).

This directory records the root-local declaration only; it does not vendor or
hand-edit generated SDK output. Authority: `sdkwork-specs/SDK_SPEC.md` and
`sdkwork-specs/SDK_WORKSPACE_GENERATION_SPEC.md`.
