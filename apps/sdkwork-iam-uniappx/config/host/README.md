# config/host

Platform host metadata for the `sdkwork-iam-uniappx` root: bundle/package
identity references, permission references, signing reference names, and store
lane references.

Signing private keys, tokens, API keys, and database credentials are forbidden
here. App ids and minimum versions are materialized into `manifest.json` from the
checked-in host example; committed manifest values must match the example or
remain placeholders.

Authority: `sdkwork-specs/UNIAPP_X_APP_ARCHITECTURE_SPEC.md` §3 and §12.
